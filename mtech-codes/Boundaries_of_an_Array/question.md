You are given an array of integers. Your task is to determine the minimum and the maximum element present in the array.

Input Format

The first line contains an integer N — the number of elements in the array.

The second line contains N space-separated integers, representing the elements of the array.

Constraints

The number of elements, N, is between 1 and 100,000.

Array elements are integers in the range -10^9 to 10^9.

Output Format

Print two integers separated by a space:

The minimum element in the array

The maximum element in the array

Sample Input 0

5
1 2 3 4 5
Sample Output 0

1 5
Sample Input 1

6
-3 0 7 -2 9 4
Sample Output 1

-3 9
